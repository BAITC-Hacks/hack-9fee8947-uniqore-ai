## Браузерная проверка

Использовался [локальный стенд](../../frontend/tests/assistant-browser-harness.mjs):

```bash
node frontend/tests/assistant-browser-harness.mjs
```

Он обслуживает ту же готовую сборку на порту 8878, читает API локального сервера на 8877, подменяет Responses и запрещает внешние сетевые вызовы через CSP. Использован только синтетический ключ из инструкции стенда. Стенд не входит в production-сборку.

Пройденные сценарии:

- Вкладка без ключа открывает окно с предупреждением о памяти страницы, перезагрузке и передаче данных OpenAI. Поле имеет тип password. Escape закрывает окно; повторное открытие показывает пустой ввод.
- Подключение показывает статус в шапке и вкладке, доступно удаление. Сам ввод не отправляет API-запрос и не объявляет ключ проверенным.
- Быстрый вопрос и свободный текст показывают имитированный ответ. Контракт запроса содержит фиксированный endpoint, Authorization, модель, ограничение ответа, `store: false`, `credentials: omit`, `redirect: error`, `cache: no-store`.
- В автоматически сформированном контексте отсутствуют gid, операции, соседи и полный граф; присутствуют факты выбранного клиента. Ключ отсутствует в теле запроса.
- HTTP 401/429, сетевая ошибка, неверный JSON, пустой ответ и refusal показывают понятную ошибку; текст вопроса доступен для повторной отправки. HTTP 403/400/500, incomplete и oversized дополнительно проверены unit-тестами.
- Удаление ключа во время ответа, выбор другого клиента, выход со вкладки и «Остановить» отменяют запрос. Принудительно возвращённые поздние ответы не показываются; удаление очищает и предыдущую историю.
- Таймер 45 секунд вызывает abort и русское сообщение о превышении ожидания. В режиме `slow` стенд намеренно игнорирует abort для проверки позднего ответа: сообщение проверено после ручного завершения уже отменённого mock-запроса. Это не замер реальной сети.
- После перезагрузки ключ отсутствует, при открытии ассистента снова требуется ввод. Локальные пояснения доступны через «Локальные пояснения · без API» без внешних запросов.
- На ширине 390 и 320 px исправлено переполнение шапки: ширина документа совпадает с доступной шириной. Модалка проверена визуально на широком и узком экране.

Счётчики стенда не зафиксировали передачу тестового ключа локальному API или запись через `Storage.setItem`. Отсутствие IndexedDB, cookies, URL-персистентности, логирования и серверного маршрута ключа дополнительно проверено чтением исходников; нулевой счётчик Storage сам по себе не доказывает отсутствие всех способов хранения.
