Проверено на macOS, Node 25.8.1, Python 3.12.1:

- `npm run build` и `npm run format:check` в `frontend/` — успешно.
- `git diff --check` — успешно.
- `python -m moneygraph demo --data data --out out/mobile-header --port 8765` — расчёт и проверка исходного набора успешны, приложение отвечает HTTP 200.
- Повторная проверка исправленной версии в браузере на ширинах 320, 390, 495, 600, 601, 768 и 1280 px: кнопки шапки не выходят за экран и не имеют внутреннего переполнения. На мобильных ширинах загрузка и выгрузка равны по ширине и высоте, находятся в одной строке. AI и справка выровнены по верхнему и нижнему краям, зазор между ними всегда 8 px. Проверен вид на 495 px, соответствующий предоставленному скриншоту.
- Открываются загрузка, подключение AI, справка и меню выгрузки. На 320 px проверена длинная подпись «OpenAI · ключ задан» с вымышленным ключом, без обращения к провайдеру.

Первичный независимый review не выявил визуальный недостаток, отмеченный пользователем. Исправление повторно проверено по протоколу: цель — выравнивание мобильной шапки; изменены обёртка двух кнопок, стили и сборка; расчёты, API и данные не затронуты.
