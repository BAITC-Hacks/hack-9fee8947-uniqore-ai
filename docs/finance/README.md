# Финансы — «Граф денег»

Кейс: восстановление финансовой структуры организованной группы по транзакционной сети. Пользователь решения — AML-аналитик банка.

**Статус на 23.09.2026:** подготовлены условия и согласованный план. Код решения, работоспособность интерфейса и скорость расчёта ещё не подтверждены. Реализация начинается по отдельной команде пользователя.

## Читать по порядку

1. [Условия задачи и обязательные требования](requirements.md) — структурированный пересказ для разработки; при расхождении первичен PDF.
2. [Архитектура и итерационный план](architecture.md) — проект команды: React, Python/FastAPI, светлый интерфейс и ранняя рабочая версия.
3. [Порядок разработки и выпуска](../development-workflow.md) — отдельные ветки, PR через `dev`, подтверждение локальной проверки перед `main`.

## Источники

- [ТЗ организатора, PDF](sources/case.pdf) — неизменённая предоставленная копия, сохранённая 23.09.2026; 5 страниц, текст представлен изображениями.

Этот пакет содержит документы. Упомянутые в описании данных `data/edges.parquet`, `data/nodes.parquet` и `data/transactions.parquet` предоставляются в отдельном наборе организатора; сами Parquet и стартовый код в этот коммит не включены. Ограничения использования данных приведены в ТЗ.

План адаптирован для репозитория только редакционно: частные локальные ссылки и история обсуждения заменены доступными документами и самодостаточным протоколом проверки. Технические решения, схема интерфейса и критерии приёмки сохранены.
