# Tyuin · кейс «Граф денег»

Кейс: восстановление финансовой структуры организованной группы по транзакционной сети. Пользователь решения — AML-аналитик банка.

**Статус на 23.09.2026:** реализован и локально проверен сквозной UX-сценарий: паспорт набора, глобальный поиск, top-20, объяснения групп и перечень проверки. Пользователь принял версию `1b38d0e` и разрешил слияние; замеры двух репетиций с человеком ещё не зафиксированы. [Запуск](../../README.md), [фактическая архитектура](implementation.md), [проверка сквозного пути](demo-ux-validation.md), [проверка подсветки и фильтров клиентов](demo-filter-validation.md), [сценарий демо](demo.md). [Проверка первой версии](validation.md) сохранена как история; [бренд Tyuin и исходники](../brand/README.md).
