# Пять минут живого демо

Подготовка: выполнить установку из [README](../../README.md); команда запуска — `python -m moneygraph demo --data data --out out`. Результаты не требуют ключей. На демонстрации использовать широкое окно браузера.

| Время | Действие | Что объясняет команда |
|---|---|---|
| 0:00–0:40 | Запустить `demo`, открыть localhost | Три Parquet проверяются и превращаются в общий снимок и три CSV. Время живого запуска показывается отдельно от сохранённого benchmark |
| 0:40–1:30 | Первый узел очереди, показать признаки и пороги роли, раскрыть расчёт поддержки и состав приоритета | Приоритет отвечает «кого проверить», поддержка роли — «насколько выражены признаки». Это отдельные оценки; у seed вход неполон |
| 1:30–2:30 | Сбросить фильтры, найти `100000000031787100`; клик по ребру, операции, изменение даты | Поиск открывает «Приоритеты». Наблюдаемый транзит: равные суммы ещё не доказывают происхождение денег. FIFO учитывает объём только один раз, операции одного дня не упорядочиваются |
| 2:30–3:20 | В верхнем фильтре глубины выбрать «Граница · глубина 4», выбрать клиента | 444 узла не превращаются автоматически в конечных получателей. Показать ограничение и следующий запрос данных |
| 3:20–4:00 | Сбросить фильтры, найти `100000000456947100`; затем снова сбросить фильтры, найти другого клиента и открыть его сообщество | Все 19 изолятов сохранены. Сообщества покрывают весь граф, не только крупнейшую компоненту. Верхние фильтры общие для обоих списков и графа |
| 4:00–4:30 | «Ассистент» → «Почему эта роль?» | Без API отображаются локальные факты. Внешний AI может только пояснять готовый результат |
| 4:30–5:00 | Скачать три CSV, выполнить `verify`, открыть «Справку и данные» | Артефакты совпадают со снимком интерфейса. Сводка набора и ограничения доступны в одном месте |

Для любого нового gid: сбросить фильтры, ввести полный идентификатор, Enter → гипотеза роли → численные основания и пороги → ограничения → операции. Если фильтр скрыл выбранного клиента, сохранённое досье явно отмечено как находящееся вне выборки. Не выдавать эвристические баллы за вероятность или точность и не заявлять accuracy без разметки.
