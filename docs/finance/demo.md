# Пять минут живого демо

Подготовка: выполнить установку из [README](../../README.md); команда запуска — `python -m moneygraph demo --data data --out out`. Результаты не требуют ключей. На демонстрации использовать широкое окно браузера.

| Время | Действие | Что объясняет команда |
|---|---|---|
| 0:00–0:40 | Запустить `demo`, открыть localhost | Три Parquet проверяются и превращаются в общий снимок и три CSV. Время живого запуска показывается отдельно от сохранённого benchmark |
| 0:40–1:30 | Первый узел очереди, раскрыть состав приоритета | Приоритет отвечает «кого проверить», поддержка роли — «насколько выражены признаки». У seed вход неполон |
| 1:30–2:30 | Поиск `100000000031787100`; клик по ребру, операции, изменение даты | Наблюдаемый транзит: равные суммы ещё не доказывают происхождение денег. FIFO учитывает объём только один раз, операции одного дня не упорядочиваются |
| 2:30–3:20 | Карточка «На границе наблюдения», выбрать узел | 444 узла не превращаются автоматически в конечных получателей. Показать ограничение и следующий запрос данных |
| 3:20–4:00 | Найти `100000000456947100`, затем открыть сообщество другого клиента | Все 19 изолятов сохранены. Сообщества покрывают весь граф, не только крупнейшую компоненту |
| 4:00–4:30 | «Ассистент» → «Почему эта роль?» | Без API отображаются локальные факты. Внешний AI может только пояснять готовый результат |
| 4:30–5:00 | Скачать три CSV, выполнить `verify` | Артефакты совпадают со снимком интерфейса. Показать ограничения и план масштабирования |

Для любого нового gid: сбросить фильтры, ввести полный идентификатор, Enter → роль → численные основания → ограничения → операции. Не выдавать эвристические баллы за вероятность преступления и не заявлять accuracy без разметки.
