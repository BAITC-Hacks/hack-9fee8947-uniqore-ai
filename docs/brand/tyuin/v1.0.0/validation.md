# Tyuin · локальная проверка ребрендинга

Дата: 23.09.2026. База: `main` / `73f5230`, содержащая первую рабочую версию приложения. Ветка: `feat/tyuin-brand`. Точный проверенный commit указан в PR.

**Рекомендация: принять для локальной приёмки.** Утверждённый логотип, скетчи и производный знак сохранены в версионном пакете. Приложение использует Tyuin в шапке, на старте, в заголовке вкладки, API-метаданных и CLI-описании. Сборка работает локально со всеми изображениями.

## Объём и проверка предложения

До изменения оценён переход от Uniqore.ai к отдельному имени Tyuin и утверждённой рыси. Объём — бренд-пакет, пользовательское название, изображения, акцентные цвета и документация. Внутренний модуль `moneygraph` и команды запуска сохранены. Условия организатора, аналитический код, исходные данные, эталонные CSV и предыдущие скриншоты не редактировались.

Проверка проведена по самодостаточному [протоколу репозитория](../../../development-workflow.md#проверка-изменений). После сохранения материалов проверена целостность оригиналов; после обновления приложения — сборка и запуск; итоговая версия проверена в браузере и по выдаваемым файлам.

## Выполненные проверки

| Проверка | Результат |
|---|---|
| `npm --prefix frontend run build` | Успешно: TypeScript и production-сборка Vite |
| `npm --prefix frontend run format:check` | Все файлы проходят Prettier |
| `.venv/bin/python -m pytest -q` | **26 passed**, 7,38 с; прежнее предупреждение Starlette/httpx |
| `.venv/bin/python -m moneygraph --help` | Имя Tyuin, прежние команды `run`, `demo`, `verify` |
| `.venv/bin/python -m moneygraph demo --data data --out out/tyuin-brand --port 8766` | Локальный запуск; снимок `ad6239d9995448b0`, 2 248 узлов, 88 сообществ, top-20 |
| HTTP: оба PNG | 200, `image/png`, тела побайтово совпадают с бренд-пакетом |
| HTTP: все три CSV | 200, побайтовое совпадение с `results/`, тот же `X-Analysis-ID` |
| `/openapi.json` | Заголовок `Tyuin · Финансовые связи` |
| 1280 × 720 | Логотип и рысь загружены, шапка не обрезает изображение; горизонтального переполнения нет |
| 390 × 844 | Логотип и экспорт помещаются в шапке; горизонтального переполнения нет |
| Поиск `100000000031787100` + Enter | Открывается досье точного клиента |
| «Выгрузить» | Все три ссылки CSV доступны |
| Сохранённые оригиналы | SHA-256 исходных генераций совпадают с копиями; PNG с логотипом не пересохранён |
| Документация и diff | Локальные ссылки, контрольные суммы источников кейса и отсутствие старого имени в актуальном интерфейсе проверены |

Проверка выполнена на macOS, Python 3.12.1, Node 25.8.1, через локальный FastAPI и встроенный браузер. Скриншоты этой версии: [рабочий экран 1280 × 720](previews/workbench.png), [узкий экран 390 × 844](previews/mobile-390.png). Узкий экран проверен в браузере, а не на физическом телефоне. Новых измерений качества аналитики или эффективности работы AML-аналитика не проводилось.
