# Tyuin · горизонтальный логотип v1.0.2

Дата: 23.09.2026. По замечанию пользователя немного увеличен зазор между рысью и надписью **Tyuin**. Вертикальная компоновка v1.0.1 сохранена. Итоговый PNG — 1793 × 877, с прозрачным фоном и полностью видимым воротником.

Встроенный ImageGen использовал [PNG v1.0.1](../v1.0.1/assets/tyuin-logo.png) как исходник. Публичное задание: сдвинуть весь блок надписи вправо примерно на 80 пикселей в масштабе исходника; при необходимости расширить прозрачное полотно справа. Сохранить высоту надписи, размер, написание, формы букв, палитру и облик персонажа. Завершающий проход восстановил целиком нижний край воротника и свободное поле под ним. Это растровое редактирование; редактируемый векторный мастер не создавался.

Отдельная иконка рыси осталась из v1.0.0. Для обновления копии приложения из корня репозитория:

```bash
cp docs/brand/tyuin/v1.0.2/assets/tyuin-logo.png frontend/public/tyuin-logo.png
cd frontend
npm run build
```
