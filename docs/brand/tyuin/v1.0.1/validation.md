# Проверка выравнивания логотипа Tyuin

Дата: 23.09.2026. Основание — замечание пользователя к горизонтальному логотипу. База исправления: `f4f877f`, PR #5, ветка `feat/tyuin-brand`. Точный commit новой редакции указан в PR.

До изменения проверена причина: элемент изображения центрирован в шапке, но надпись внутри PNG находится ниже её середины. Объём исправления — компоновка самого логотипа, его копии приложения, каталог бренда и новые скриншоты. Исходники v1.0.0, отдельная иконка, код интерфейса, аналитика и данные не меняются.

## Локальная проверка

- `npm --prefix frontend run build` — успешная проверка TypeScript и production-сборка.
- В браузере проверены новая надпись в шапке, соседний текст и отсутствие обрезания логотипа на 1280 × 720 и 390 × 844. Оба PNG загрузились, горизонтального переполнения нет.
- [Широкий экран](previews/workbench.png) и [узкий экран](previews/mobile-390.png) показывают фактическое приложение после пересборки.
- Контрольные суммы v1.0.0 сохранены. PNG v1.0.1 побайтово совпадает с копиями в `frontend/public/` и `moneygraph/web/`.
- Локальные ссылки документации и `git diff --check` проверены.

Это визуальная корректировка. Аналитический код не менялся; 26 тестов предыдущей редакции описаны в [отчёте v1.0.0](../v1.0.0/validation.md) и повторно для замены PNG не запускались.
