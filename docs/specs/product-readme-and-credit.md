## Приёмка

1. README понятен без ТЗ; запуск и полный основной деплой выполняются по нему без обязательного перехода в другую инструкцию.
2. Команды, внутренние ссылки и якоря проверены; исходные данные и контрольные результаты не изменены.
3. Сборка frontend, существующие тесты и локальный smoke проходят на зафиксированном commit. Подпись проверена на 1280 и 390 px; нет перекрытий или горизонтального скролла.
4. Зафиксированы версия, сценарии и результаты локальной проверки; пользователь подтвердил приёмку до слияния в main.
5. После слияния тот же итоговый код развёрнут на существующей VM с сохранением Caddy и томов сертификатов; HTTPS, подпись, поиск, API и три CSV проверены. Предыдущий образ сохранён для отката.
6. Только после выполнения и приёмки задача переносится в done. До выполнения облачного шага он отмечается незавершённым, без заявления об успешном деплое.

API, форматы CSV, алгоритмы, исходные Parquet и права доступа этой итерацией не меняются.
