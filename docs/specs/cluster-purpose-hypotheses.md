# Объяснить назначение кластеров через структуру потоков

Статус: реализовано и технически проверено на `22ec2b8` как зависимость [демо-сценария](finance-demo-rehearsal.md); ожидается пользовательская локальная приёмка. Задача остаётся [в работе](../backlog.md). [Отчёт проверки](../finance/demo-ux-validation.md).

## Задача
Как AML-аналитик, я хочу понимать возможное назначение выделенной группы и основания этой гипотезы, чтобы решать, что проверять дальше.

Выполнено в составе первоочередного демо-сценария: по обязательному пункту 4 кейса в `clusters.csv` требуется гипотеза о назначении кластера.

## Проблема до реализации
Поле `hypothesis` сейчас повторяет размер, число seed, преобладающую роль и внутренний оборот. Оно не объясняет возможную функцию группы. Например, сообщество 48: 26 узлов, 14 seed, преобладает периферия — этого недостаточно для содержательной гипотезы.

## Что сделать
- Вывести объяснимые правила групповых гипотез из наблюдаемой структуры и направлений потоков: возможный сбор средств, распределение, транзит или смешанная структура.
- Указывать конкретные рассчитанные основания и ключевые узлы, а также ограничения наблюдения.
- Если признаки недостаточны, явно писать, что назначение определить нельзя, с причиной.
- Использовать одинаковые гипотезы в CSV, API и интерфейсе; документировать правила.

## Результат реализации

Добавлены правила сбора, распределения, смешанной структуры, промежуточного прохождения и обоснованной неопределённости. Численные основания и ограничения согласованы в CSV/API/карточке группы. Проверены синтетические структуры, пороги и реальные 88 групп; состав групп и агрегаты сохранены. Подробности и команды — в [отчёте](../finance/demo-ux-validation.md). Технические критерии ниже выполнены; пользовательская приёмка перед merge остаётся отдельным условием.

## Критерии готовности
- [x] У каждого кластера есть содержательная гипотеза либо обоснованная неопределённость; текст не ограничивается пересказом размера и оборота.
- [x] Вывод воспроизводимо следует из метрик и правил, без списков «правильных» gid, внешнего обогащения и вымышленных атрибутов.
- [x] Учтены изоляты, граница четвёртого колена и неполные потоки; сообщества не объявляются преступными группами.
- [x] Проверены обычное сообщество, сообщество с несколькими seed, пограничный случай и изолят; численные основания согласованы с исходными данными.
- [x] CSV/API/интерфейс показывают согласованный результат; сохранены схемы выгрузок и покрытие всех 2 248 узлов.
- [x] README и отчёт проверки обновлены; выполнены затронутые тесты и сквозной пересчёт менее 300 секунд.
