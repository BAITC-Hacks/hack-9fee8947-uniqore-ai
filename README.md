## Кейс «Финансы»: Граф денег

Планируемое решение помогает AML-аналитику получить из графа переводов очередь клиентов для проверки, увидеть основания их структурных ролей и ограничения исходных данных.

**Текущий статус:** подготовлены условия задачи и план архитектуры. Реализация приложения ещё не начата; команды запуска, интерфейс и показатели скорости из плана пока не являются проверенными возможностями продукта.
