# Данные кейса «Финансы»

Три неизменённых Parquet-файла предоставлены организатором для использования в рамках HackAlem AI. Они включены в конкурсный репозиторий для самостоятельного локального воспроизведения решения.

- [Описание схем и параметров сбора](../docs/finance/sources/data-description.md).
- [Условия и ограничения использования](../docs/finance/requirements.md).

Это обезличенный учебный набор с синтетическими идентификаторами. Выводы приложения — гипотезы по наблюдаемой структуре. Данные не лицензируются командой для иного использования.
