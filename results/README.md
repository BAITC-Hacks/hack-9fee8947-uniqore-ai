# Проверенный результат алгоритма 1.0.0

Три CSV получены из неизменённых файлов `data/*.parquet`. Они служат доступным результатом для проверки и не используются приложением вместо пересчёта.

- `nodes_roles.csv`: 2 248 узлов, включая 19 изолятов.
- `clusters.csv`: 88 сообществ.
- `top_nodes.csv`: 20 первых узлов в порядке приоритета.
- `manifest.json`: версии, параметры, SHA-256 входов и CSV.
- `benchmark.json`: первый запуск в новом Python-окружении, время всего процесса, память и сравнение обработки границы.
- `repeat-benchmark.json`: запуск в отдельной копии исходников с теми же зависимостями; файловый кэш ОС не очищался.

Проверка из корня репозитория после установки зависимостей:

```bash
python -m moneygraph verify --data data --out results
```

Свежий пересчёт: `python -m moneygraph run --data data --out out`. Три новых CSV должны побайтово совпадать с этой версией при тех же входах и зафиксированных зависимостях. Время и окружение в manifest могут отличаться.
