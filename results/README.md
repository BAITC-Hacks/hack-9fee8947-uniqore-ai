# Проверенный результат алгоритма 1.1.0

Три CSV получены из неизменённых файлов `data/*.parquet`. Они служат доступным результатом для проверки и не используются приложением вместо пересчёта.

- `nodes_roles.csv`: 2 248 узлов, включая 19 изолятов.
- `clusters.csv`: 88 сообществ.
- `top_nodes.csv`: 20 первых узлов в порядке приоритета.
- `manifest.json`: версии, параметры, SHA-256 входов и CSV.
- `demo-scenario-benchmark.json`: текущий алгоритм 1.1.0, новый процесс в установленном окружении, 4,2752 с с импортами; кэш ОС не очищался.
- `benchmark.json`: исторический алгоритм 1.0.0, первый запуск в новом Python-окружении, время всего процесса, память и сравнение обработки границы.
- `repeat-benchmark.json`: исторический алгоритм 1.0.0, запуск в отдельной копии исходников с теми же зависимостями; файловый кэш ОС не очищался.

Проверка из корня репозитория после установки зависимостей:

```bash
python -m moneygraph verify --data data --out results
```

Свежий пересчёт: `python -m moneygraph run --data data --out out`. Три новых CSV должны побайтово совпадать с этой версией при тех же входах и зафиксированных зависимостях. Время и окружение в manifest могут отличаться.

В версии 1.1.0 обновлены полные основания `why` и гипотезы назначения групп. `nodes_roles.csv` побайтово совпадает с 1.0.0; ранги/роли/оценки top-20 и агрегаты групп сохранены. Предыдущие файлы измерений оставлены как история и не являются измерениями новой версии.
